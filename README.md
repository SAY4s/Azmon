# 📚 Azmon | سامانه آزمون آنلاین خوارزمی

سامانه‌ی برگزاری آزمون آنلاین برای **مرکز آموزشی خوارزمی** (محمدیه، قزوین) — یک اپلیکیشن تک‌صفحه‌ای (Single Page) که با HTML، CSS و جاوااسکریپت خالص (بدون فریم‌ورک) پیاده‌سازی شده و به‌صورت کاملاً سمت کلاینت اجرا می‌شود.

این سامانه امکان برگزاری آزمون‌های **ICDL** و **دیپلم رسمی فنی‌وحرفه‌ای** را با بانک سوالِ قابل‌ویرایش (فایل‌های متنی ساده) فراهم می‌کند.

---

## ✨ امکانات

- 🔐 **ورود با رمز عبور** ساده، بدون نیاز به بک‌اند یا دیتابیس
- 🎲 **آزمون تصادفی ICDL** با انتخاب خودکار سوالات از بانک سوال
- 🎓 **آزمون دیپلم** با ۵ گرایش قابل‌انتخاب:
  - کاربر رایانه
  - تایپ رایانه
  - سیاه و سفید
  - گرافیک رایانه
  - طراحی رنگی
- ⏱️ **تایمر شمارش معکوس** با هشدار رنگی در دقایق پایانی
- 🔀 **جابه‌جایی تصادفی گزینه‌ها** در هر بار اجرای آزمون
- 📊 **صفحه‌ی نتایج** با تفکیک پاسخ‌های درست، غلط و بی‌پاسخ + وضعیت قبولی/مردودی
- 🔢 **شبکه‌ی شماره سوالات** برای پیمایش سریع بین سوالات
- 🖼️ **اسلایدشوی تبلیغاتی** (بنر) از تصاویر داخل پوشه‌ی `poster`
- ⌨️ **میانبرهای صفحه‌کلید** (جهت‌ها برای جابه‌جایی، اعداد ۱ تا ۴ برای انتخاب گزینه، Ctrl+Enter برای پایان آزمون)
- 📱 **طراحی واکنش‌گرا (Responsive)** با نمای تمام‌صفحه مخصوص موبایل حین آزمون

## 🗂️ ساختار پروژه

```
Azmon/
├── index.html          # صفحه‌ی اصلی سامانه (ورود، انتخاب آزمون، اجرای آزمون، نتایج)
├── icdl.html            # صفحه/محتوای مرتبط با آزمون ICDL
├── dip.html              # صفحه/محتوای مرتبط با آزمون دیپلم
├── pass.txt             # رمز عبور ورود به سامانه (متن ساده)
├── qizICDL.txt           # بانک سوالات آزمون ICDL
├── karbarquiz.txt        # بانک سوالات «کاربر رایانه»
├── typequiz.txt          # بانک سوالات «تایپ رایانه»
├── blackwhite.txt        # بانک سوالات «سیاه و سفید»
├── graf.txt              # بانک سوالات «گرافیک رایانه»
├── rang.txt              # بانک سوالات «طراحی رنگی»
├── font/                 # فونت اختصاصی سایت (SiteFont)
└── poster/               # تصاویر بنر/اسلایدشو (نسبت A4 عمودی)
```

## 🚀 راه‌اندازی

از آنجا که پروژه کاملاً استاتیک است (فقط HTML/CSS/JS)، برای اجرا فقط به یک وب‌سرور ساده نیاز دارید (باز کردن مستقیم فایل با `file://` به دلیل محدودیت `fetch` روی برخی مرورگرها ممکن است کار نکند).

1. مخزن را کلون کنید:
   ```bash
   git clone https://github.com/SAY4s/Azmon.git
   cd Azmon
   ```

2. یک سرور محلی اجرا کنید (یکی از روش‌های زیر):
   ```bash
   # با پایتون
   python3 -m http.server 8000

   # یا با Node.js
   npx serve .
   ```

3. مرورگر را باز کرده و به آدرس زیر بروید:
   ```
   http://localhost:8000
   ```

4. با رمز عبور تعریف‌شده در `pass.txt` وارد سامانه شوید.

> همچنین می‌توانید پروژه را روی **GitHub Pages** یا هر سرویس هاست استاتیک دیگر (Netlify، Vercel و...) مستقر کنید.

## 📝 فرمت بانک سوالات

هر سوال در فایل‌های `.txt` به‌صورت ۶ خط پشت سر هم و با یک خط خالی جدا از سوال بعدی نوشته می‌شود:

```
متن سوال
گزینه الف
گزینه ب
گزینه ج
گزینه د
د
```

خط ششم فقط باید یکی از حروف `الف`، `ب`، `ج`، `د` (یا معادل انگلیسی `a/b/c/d`) باشد که گزینه‌ی صحیح را مشخص می‌کند.

برای افزودن سوال جدید کافی است الگوی بالا را در فایل مربوط به همان گرایش رعایت کنید.

## ⚙️ سفارشی‌سازی

| بخش | نحوه‌ی تغییر |
|---|---|
| رمز عبور ورود | ویرایش محتوای فایل `pass.txt` |
| بانک سوالات | ویرایش فایل‌های `.txt` مربوطه با فرمت بالا |
| بنرهای تبلیغاتی | افزودن تصویر (jpg/png/webp/gif) به پوشه‌ی `poster/` |
| فونت سایت | جایگزینی فایل در پوشه‌ی `font/` |
| رنگ‌بندی و ظاهر | ویرایش متغیرهای CSS (`:root`) در ابتدای `index.html` |
| تعداد سوالات هر آزمون / زمان آزمون | ویرایش مقادیر مربوطه در بخش اسکریپت `index.html` |
